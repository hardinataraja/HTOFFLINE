CARA HUBUNG TANPA INTERNET

  1. Salah satu HP mengaktifkan Hotspot Pribadi (Matikan paket data internet Anda agar murni offline).
  2. HP pasangan wajib terhubung ke Hotspot tersebut.
  3. Buka aplikasi ini di kedua HP (versi install APK/cached website).
  4. Orang Pertama: Klik GENERATE pada Langkah 1, lalu klik SALIN dan kirim teks tersebut ke pasangan (bisa via Bluetooth/aplikasi transfer lokal).
  5. Orang Kedua: Tempel teks tadi ke kolom Langkah 2, lalu klik TERIMA TOKEN (A). Setelah itu, akan muncul token baru di Langkah 1 Orang Kedua. Salin dan berikan balik ke Orang Pertama.
  6. Orang Pertama: Tempel token balasan tersebut di kolom Langkah 2 miliknya, lalu klik SAMBUNGKAN (B).
  7. Status akan berubah menjadi TERHUBUNG. Sekarang Anda berdua bebas berbicara secara offline!

Hubungkan dengan pasangan untuk mengaktifkan tombol bicara.
